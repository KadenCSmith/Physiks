# Source provenance

The reusable shell, custom navigation icons, thin typography, black canvas, drawer portals, Finder/Toolbox behavior, and playback layout were adapted from Kaden's existing projects:

- [Zombie Fire Suppression Sim](https://github.com/KadenCSmith/zombie-fire-suppression-sim), whose v0.20.0 shell informed the interface.
- [Vibrations Physics Sim](https://github.com/KadenCSmith/vibrations-physics-sim), based on commit `bc00015f5aaf93b45158ac82f02d279560f0c3ab` when this starter was extracted.

This repository generalizes application branding, model registration, parameters, plots, guides, formula grouping, and state sampling. Its small oscillator and relaxation examples are teaching demonstrations created for the starter. It does not include the original study screenshots, lecture photos, PDFs, fire assets, app histories, or saved user settings.

React, Vite, TypeScript, KaTeX, Lucide, Vitest, and Oxlint are external dependencies with their own licenses. Their installed package notices remain with those packages. No new license has been assigned to Kaden's original or adapted application source.
